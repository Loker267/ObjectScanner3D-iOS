# ObjectScanner3D (iOS)

Полноценное iOS-приложение для создания 3D-моделей предметов по снимкам камеры с использованием датчиков **6DoF** (ARKit VIO: акселерометр + гироскоп + камера) и встроенным **интерактивным 3D-просмотрщиком** с поддержкой **AR (дополненной реальности)**.

Разработано специально с учетом iPhone без лидара (**iPhone 11, iPhone 11 Pro** и новее).

---

## 🚀 Возможности

1. **Умный 6DoF автозахват (Smart Trigger):**
   * В реальном времени отслеживает положение смартфона в пространстве ($X, Y, Z$ и углы поворота).
   * Автоматически делает четкий снимок, когда телефон смещается на ~10–12 см или поворачивается на ~13° вокруг объекта.
   * Исключает смазанные кадры и перекрывает слепые зоны.
   * Сохраняет стандартный `transforms.json` (NeRF / 3D Gaussian Splatting / COLMAP формат) и `sparse_cloud.ply` (разреженное облако точек VIO).

2. **Встроенный интерактивный 3D-просмотрщик:**
   * Вращение на $360^\circ$, приближение (pinch-to-zoom) и панорамирование пальцем.
   * Переключение между текстурированной моделью и полигональной сеткой (**Wireframe**).
   * Поддержка стандартных форматов: `.usdz`, `.obj`, `.scn`, `.dae`, `.ply`.

3. **Режим дополненной реальности (AR Quick Look):**
   * Кнопка **«Посмотреть в AR»** позволяет спроецировать получившуюся модель прямо на ваш реальный стол или пол через камеру iPhone в масштабе 1:1.

4. **3D Галерея и импорт:**
   * Список всех ваших моделей с размером и датой.
   * Кнопка **«+»** для импорта готовых `.obj` / `.usdz` файлов из приложения «Файлы» или облака.
   * Кнопка создания тестовой 3D-модели для проверки вьювера сразу после установки.

## 📱 Стек технологий

* **Язык:** Swift 5 / SwiftUI
* **Трекинг 6DoF:** ARKit (`ARWorldTrackingConfiguration`, Visual-Inertial Odometry)
* **3D Рендеринг:** SceneKit + QuickLook (AR Quick Look)
* **Минимальная версия iOS:** iOS 15.0+

## 🛠️ Как запустить на iPhone

### Вариант 1: Через Xcode (если есть Mac)
1. Откройте файл `ObjectScanner3D.xcodeproj` в Xcode.
2. В настройках проекта (Signing & Capabilities) выберите свой бесплатный Apple ID (Personal Team).
3. Подключите iPhone 11 / 11 Pro проводом и нажмите **Run (Cmd + R)**.

### Вариант 2: Через GitHub Actions (без Mac)
1. Загрузите эту папку в свой GitHub-репозиторий.
2. Перейдите во вкладку **Actions** $\rightarrow$ **Build iOS IPA** $\rightarrow$ **Run workflow**.
3. Скачайте собранный файл `ObjectScanner3D-unsigned.ipa` из артефактов.
4. Установите его на iPhone с помощью **AltStore**, **SideStore** или **Sideloadly** через ПК с Windows.

## 🖥️ Обработка на ПК / Сервере (`ReconstructionServer`)

В папке `ReconstructionServer` лежит скрипт `server.py` для превращения датасета с iPhone в готовую 3D-модель:

```bash
cd ReconstructionServer
pip install -r requirements.txt
python server.py "Путь_к_папке_Scan_XXXXXX" --format obj
```

Благодаря тому, что в `transforms.json` уже записаны точные 6DoF-координаты каждого кадра, генерация через **3D Gaussian Splatting** или **Instant-NGP** происходит в разы быстрее, чем при обычном подборе с нуля через COLMAP.
